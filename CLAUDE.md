# SPT Trader Builder

- To make, change or check quests, quest text, assort unlocks or quest zones, use the command line in `src/cli`
  (`python -m cli` from `src`) rather than editing the JSON by hand: it fills in ids and defaults, resolves names and runs
  the app's checks. Read `src/cli/README.md` first.
- To change the command line, the map import or the zone checks, read `src/cli/DEVELOPING.md` first.
